# 週年慶｜第一章 B2 停車場

3D 第一人稱動作恐怖遊戲原型。三十年前被拆掉的廟，原址蓋起了一間吃人的百貨公司，玩家扮演快被遺忘的小神，進入廢棄百貨救出被困的靈魂。

## 遊玩方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或建置。建議使用電腦、鍵盤與滑鼠。

| 按鍵 | 動作 |
|---|---|
| WASD | 移動 |
| 滑鼠 | 轉動視角 |
| 左鍵 | 聖光波（長按蓄力） |
| 右鍵 | 光刃 |
| Shift | 光翼瞬步 |
| Q / E / R / X | 神域結界／天罰光柱／照見／神降 |
| 按住 F | 救出靈魂 |
| U | 升級神力 |
| Esc / P | 暫停 |

## 技術

- 單一 HTML 檔，使用 three.js r128（cdnjs）
- 音效由 Web Audio 即時合成
- 存檔：自動存在瀏覽器的 localStorage

## 部署

純靜態網站，可直接部署到 Vercel：匯入這個 repo，Framework Preset 選 **Other**，不需要 Build Command。
